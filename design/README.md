# CareSlot UI Designs & Stitch References

This folder contains the visual designs, wireframes, and Stitch UI references for CareSlot MVP.

### Design System & Style Guide:
- **Style Line:** "Clean medical web app, white background, calming teal primary color, rounded cards, Inter font, mobile-first, accessible contrast."
- **Primary Color:** Teal (#0D9488 / #14B8A6)
- **Background:** White / Slate-50 (#F8FAFC)
- **Text:** Slate-900 / Slate-600
- **Accent/Badges:**
  - Available: Green (#10B981)
  - Delayed: Amber (#F59E0B)
  - On Leave: Red (#EF4444)

### Screen Reference Modules:
1. **Landing / Search:** Hospital doctor booking home page, search bar, department chips, doctor cards with live status badges.
2. **Doctor Profile & Booking:** Doctor details, date picker strip, grid of time slots, confirmation modal/drawer.
3. **Patient Appointments:** Upcoming and Past tabs, status cards, Cancel/Reschedule actions, notification bell.
4. **Doctor Dashboard:** Status switcher (Available / Delayed with minutes / On leave), today's appointment timeline, mark completed.
5. **Admin Panel:** Doctors, departments, appointments management tables and Add Doctor form.
6. **Auth:** Login and signup screen with role selection (Patient / Doctor).
